# 🧛 Ekşi Sözlük Dracula Theme

A dark theme for [eksisozluk.com](https://eksisozluk.com) based on the [Dracula](https://draculatheme.com) color palette. Ad-free, readable, and easy on the eyes.

![Stylus](https://img.shields.io/badge/Stylus-Compatible-bd93f9?style=flat-square)
![License](https://img.shields.io/badge/License-MIT-50fa7b?style=flat-square)

## Color Palette

| Color          | Hex       | Usage                        |
|----------------|-----------|------------------------------|
| 🟣 Purple      | `#bd93f9` | Links, accents               |
| 🩷 Pink        | `#ff79c6` | Headings, highlights         |
| 🩵 Cyan        | `#8be9fd` | Entry details, timestamps    |
| 🟢 Green       | `#50fa7b` | Upvotes                      |
| 🔴 Red         | `#ff5555` | Downvotes, errors            |
| 🟡 Yellow      | `#f1fa8c` | Hover feedback               |
| ⬛ Background  | `#282a36` | Page background              |
| 🔲 Surface     | `#44475a` | Cards, dropdowns             |

## Installation

1. Install the [Stylus](https://add0n.com/stylus.html) browser extension
2. Open the `style.css` file from this repo
3. Copy the contents and create a new style in Stylus for `eksisozluk.com`

## Features

- Full Dracula color scheme across all UI elements
- Custom scrollbar styling
- Cleaner layout with hidden sidebar ads
- Styled buttons, inputs, dropdowns, and navigation
- Custom Ekşi Sözlük logo
